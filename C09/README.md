# 42 Piscine - C09

This repository contains the solutions for the **C09** project of the 42 Piscine. The goal of this module is to create static libraries (`libft.a`), manage Makefiles with specific directory layouts, and implement advanced string splitting functions.

## 🛠️ Exercise Overview

| Directory | File / Function Name | Description | Status |
| :--- | :--- | :--- | :---: |
| **ex00/** | `libft_creator.sh` & files | Shell script and source files to create the `libft.a` static library[cite: 100]. | ✅ |
| **ex01/** | `Makefile` | Makefile to compile `libft.a` from the `srcs/` directory using headers from `includes/`[cite: 101]. | ✅ |
| **ex02/** | `ft_split` | Splits a string into an array of substrings using a set of characters as separators[cite: 103]. | ✅ |
